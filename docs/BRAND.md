# Cortexia Island brand

An original C-shaped sculptural mark surrounds a floating island. OLED black ceramic, brushed titanium, restrained ice cyan and champagne accents connect the icon to the live network and energy colors.

## Assets

- `assets/brand/app-icon-master.png`: original transparent PNG generated in the ChatGPT browser UI.
- `assets/icon.png`: 512 px application icon.
- `assets/icon.ico`: 16–256 px multi-resolution Windows installer/application icon.
- `assets/tray.png`: 32 px tray icon.
- `assets/mark.png`: 96 px source used at a small size in the island.
- `assets/brand/icon-preview.png`: 256 px preview.
- `assets/brand/hero.png`: wide campaign/README artwork.
- The campaign was regenerated in the same ChatGPT browser conversation for the electricity-first direction, with the tagline **Power. Cost. Clarity.**

Run `npx electron scripts/derive-brand.cjs` to recreate packaging sizes from the master. This preserves transparency; it is resizing/format conversion, not re-generation. Source and derived art remain in the repository.

Generated on 2026-10-07 at the owner’s request through ChatGPT’s browser **Create image** tool. The requested model was ChatGPT Image 2; the UI did not expose a verifiable model version, so no model identity is asserted in asset metadata.

Master art direction: a continuous C-shaped emblem around a floating island, black ceramic and dark titanium with physically plausible studio reflections, ice-cyan edge and small champagne accent, centered on a rounded black tile with transparent outer background. No Apple or third-party marks. Hero direction: the same identity, OLED black textured stage and clean Cortexia Island typography. Brand art is independent of the reference post.
