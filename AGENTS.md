# Project working instructions

- Communicate with the owner in Turkish. Verify the real OS and shell each session.
- Read `docs/HANDOFF.md` first. Preserve local changes; never use destructive reset/force push.
- Work in this Desktop project folder on Windows; discover the real Desktop on macOS. Reinstall dependencies with `npm ci` on each device.
- Keep tracked data, addresses and credentials out of Git. Showcase images must use labeled fixtures.
- Run relevant tests, `npm run check`, desktop smoke and dependency audit for changed behavior. Keep estimates and measurements distinct.
- Keep version, changelog and release notes consistent. Before a tag, check architecture-specific packages and update metadata. Do not claim signing, notarization or full-device tests that have not occurred.
- No agents/delegation are required for ordinary work.
